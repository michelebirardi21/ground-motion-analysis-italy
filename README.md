# Parametric, Locally Adaptive, and Non-Parametric Geostatistical Analysis of Ground-Motion Site Effects in Italy

The PGA and PGV folders contain the analyses for Peak Ground Acceleration and Peak Ground Velocity, respectively. While the scripts share a similar structure, they feature specific initializations tailored to each metric.

The `Esplorazione.R` file contains commands for exploring the dataset, visualizing its variables, and obtaining general information about its structure. To run this script, the files `ITA_18.R` and `dataset_martina.csv` must be loaded.

The `Caso Stazionario.R` file contains the code implementing the stationary model. To run this script, the files `ITA_18.R` and `dataset_martina.csv` must be loaded.

The `RDD_Rgeostats.R` file contains the code implementing the non-stationary **Random Domain Decomposition** model. To run this script, the files `ITA_18.R`, `dataset_martina.csv`, and `Utilities.r` must be loaded.

The `Non_Parametrico_parallelo.R` file contains the code implementing the non-parametric model. To run this script, the files `ITA_18.R`, `dataset_martina.csv`, and `utils2.R` must be loaded.

The `Ponte Completo.R` file contains the code used to compare the different models across several metrics and maps, relying on the `.rds` files generated by running the model scripts.

Before running the scripts after downloading the repository, please make sure to update the file paths currently specified in the code so that they correctly point to the location of the required files on your local machine.
